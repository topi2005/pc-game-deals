# PC Game Deals

## Run Part A (console)
1. Install Node.js from nodejs.org if you don't have it.
2. Open a terminal in this folder.
3. Run: `node partA.js`

## Run Parts B and C (web page)
1. Double-click `index.html` to open it in your browser. No server or install needed.
2. Type in the box to search; tick "On sale only" to filter.

## Files
- `data.js` the deals data
- `functions.js` the logic (Part A)
- `partA.js` prints results to the console
- `index.html`, `style.css`, `app.js` the web page (Parts B and C)
- `assumptions.md` my assumptions
